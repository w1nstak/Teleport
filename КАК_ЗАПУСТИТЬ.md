# Как запустить Teleport — от сервера до телефона

Полный путь: **сервер в Amvera → проверка → приложение на телефоне**.

---

## Часть 1. Сервер в Amvera (обязательно)

### 1.1 Сборка прошла успешно

1. [cloud.amvera.ru](https://cloud.amvera.ru) → проект **teleport**
2. Вкладка **Сборка** — статус **«Приложение запущено»** (зелёный)
3. Если ошибка — откройте лог. Код уже в Git, конфиг: **Docker**, порт **5000**

### 1.2 Переменные окружения

**Настройки → Переменные окружения** → добавить:

```
DATA_DIR=/data
PUBLIC_URL=https://teleport.w1nst.amvera.io
```

Сохранить → **Пересобрать** (если кнопка есть).

### 1.3 Домен HTTPS

**Настройки → Доменные имена → Добавить**

| Поле | Значение |
|------|----------|
| Тип подключения | HTTPS |
| Тип домена | Бесплатный домен Amvera |

**Применить**. Через 1–3 минуты появится URL (скорее всего `https://teleport.w1nst.amvera.io`).

### 1.4 Проверка сервера

В браузере на телефоне или ПК:

```
https://teleport.w1nst.amvera.io/health
```

Должно показать: `{"ok": true, ...}`

**Веб-версия мессенджера** (можно пользоваться сразу):

```
https://teleport.w1nst.amvera.io/
```

Зарегистрируйтесь → войдите → найдите пользователя в поиске → пишите в чат.

> Пока `/health` не открывается — приложение на телефоне тоже не заработает.

## Часть 2. Приложение на Android

URL сервера уже прописан: `https://teleport.w1nst.amvera.io`

### 2.1 Собрать APK

Нужна **Java 11+** (не Java 8).

```powershell
cd "c:\Users\artem\OneDrive\Документы\neon\teleport"
.\BUILD_APK.bat
```

Готовый файл: `teleport\Teleport.apk`

### 2.2 Установить на телефон

1. Скопируйте `Teleport.apk` на телефон (USB, Telegram, почта)
2. Откройте файл → **Установить** (разрешите установку из неизвестных источников)

### 2.3 Первый вход

1. Откройте **Teleport**
2. **Зарегистрироваться без номера** — имя, @username, пароль (от 8 символов)
3. Или **Войти по юзернейму**, если уже регистрировались в веб-версии

Ничего в настройках сервера вводить **не нужно**.

## Часть 3. Приложение на iPhone

Нужен **Mac + Xcode**:

```bash
cd teleport/ios
brew install xcodegen
xcodegen generate
./build_ipa.sh
```

Установите `Teleport.ipa` на iPhone (через Xcode или AltStore).

URL уже в сборке: `https://teleport.w1nst.amvera.io`

---

## Часть 4. Два телефона — общаться

1. **Телефон 1:** регистрация `@user1`
2. **Телефон 2** (или веб): регистрация `@user2`
3. В поиске чатов введите `user2` → откройте чат → отправьте сообщение
4. Сообщения приходят в реальном времени (WebSocket)

## Частый порядок проблем

| Симптом | Решение |
|---------|---------|
| `/health` не открывается | Домен HTTPS не подключён или сборка упала — смотрите лог в Amvera |
| 502 на сайте | Подождите сборку; проверьте `DATA_DIR=/data` |
| «Сервер недоступен» в приложении | Сначала почините `/health` в браузере |
| APK не собирается | Установите Java 11+: [adoptium.net](https://adoptium.net) |
| Другой URL домена | `.\setup_public_url.ps1 https://ваш-реальный-url.amvera.io` и пересоберите APK |

## Быстрый тест без APK

1. Дождитесь работающего `https://teleport.w1nst.amvera.io/health`
2. Откройте `https://teleport.w1nst.amvera.io/` в Safari/Chrome на телефоне
3. Зарегистрируйтесь и пользуйтесь как мессенджером в браузере
