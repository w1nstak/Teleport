# Настройка Teleport

## Всё уже готово — нужно только вставить api_id и api_hash

## Шаг 1: Получить API ключи

1. Зайди на https://my.telegram.org
2. Войди по номеру телефона
3. Перейди в "API development tools"
4. Создай новое приложение (любое название)
5. Получишь `api_id` (число) и `api_hash` (строка)

## Шаг 2: Вставить ключи в проект

Открой файл `Teleport/Services/TelegramService.swift` и замени:

```swift
static let apiId: Int32 = 0        // <-- Вставь свой api_id
static let apiHash: String = ""     // <-- Вставь свой api_hash
```

## Шаг 3: Запуск

TDLib уже подключен через Package.swift (SPM). Xcode скачает его автоматически.

## Запуск

1. Открой проект в Xcode
2. Выбери iOS Simulator или реальное устройство
3. Запусти — введи номер телефона
4. Придёт код В TELEGRAM (не по SMS!) — введи его
5. Все чаты, сообщения, группы, каналы подтянутся автоматически

## Как это работает

- TDLib подключается к серверам Telegram напрямую
- Получает ВСЕ данные аккаунта: чаты, сообщения, контакты, файлы
- Отправка сообщений идёт через Telegram — собеседники видят их в обычном ТГ
- По сути Teleport = альтернативный клиент Telegram с другим UI

## Важно

- Это ЛЕГАЛЬНО: Telegram разрешает сторонние клиенты
- Данные хранятся на устройстве (TDLib создаёт локальную БД)
- Двухфакторная аутентификация поддерживается
- Сессия видна в "Настройки → Активные сессии" в Telegram
